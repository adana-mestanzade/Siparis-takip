# NDustrio Market Demo

N'Dustrio ürün mimarisi, bayi/servis ağı ve 2026 katalog yaklaşımından ilham alan Amazon/Trendyol tarzı modern pazaryeri vitrini.

## Özellikler

- Endüstriyel mutfak ekipmanları için kategori odaklı ana sayfa
- Ürün arama, vitrin kartları, puan, kampanya etiketi ve sepete ekleme aksiyonları
- Kurumsal teklif, bayi, servis, KVKK ve çoklu dil modüllerine hazır içerik kurgusu
- Mobil uyumlu responsive tasarım

## Çalıştırma

```bash
npm install
npm run dev
```

## Üretim Derlemesi

```bash
npm run build
```
